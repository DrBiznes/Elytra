# Waystone Wings

Waystone Wings is a NeoForge mod for Minecraft 1.21.1 that turns the vanilla Elytra into an end-game progression component for Waystones and Create.

## What it changes

- Blocks Elytra gliding universally, including direct fall-flying state changes and firework boosting.
- Prevents equipping an Elytra and safely moves an already-equipped one back into inventory (or drops it if inventory is full).
- Presents the same vanilla item as the **Elytra Warp Core**, with a purpose tooltip and custom inventory model. End Ship loot and existing inventories remain untouched.
- Adds a Calibrated Warp Core assembled through Create.
- Replaces all 54 craftable recipe IDs shipped by Waystones 21.1.45, including every Waystone variant, Sharestone, Portstone, Warp Plate, Warp Stone, scroll, dust, shard, Twinbound Feather, and Epitaph recipe.
- Keeps the original recipes available behind a compatibility config switch.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.250 or newer 21.1.x
- Create 6.0.10
- Waystones 21.1.45
- Balm 21.0.65
- Java 21

The Gradle development runs download the exact public CurseForge releases automatically.

## Build

```powershell
.\gradlew.bat build
```

The distributable JAR is written to `build/libs/waystone_wings-1.0.0.jar`.

## Artwork

The Elytra Warp Core is an intentionally simple 16x16 indexed-color sprite. It is generated entirely in code—without generative-image tooling or resampling—by running:

```powershell
python .\scripts\generate_texture.py
```

The script also writes a nearest-neighbor preview to `docs/art/elytra_warp_core_16x_preview.png`.

## Configuration

Open **Mods → Waystone Wings → Config** for NeoForge's native configuration UI. Common and Client pages are divided into focused sections with breadcrumbs, translated tooltips, validated controls, unlimited undo, reset-to-default buttons, automatic saving, and restart prompts.

Gameplay and recipe settings are written to `config/waystone_wings-common.toml`. Name, tooltip, and inventory-model settings are written to `config/waystone_wings-client.toml`. Recipe options require a world/server restart; the inventory model option requires a client restart. On a dedicated server, gameplay and recipe settings must be changed in the server's own common config.

See [the recipe matrix](docs/RECIPE_MATRIX.md) and [the original project plan](PROJECT_PLAN.md) for design details.
