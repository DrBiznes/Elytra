# Changelog

## 0.1.0

- Disable Elytra gliding and firework boosting in every dimension.
- Prevent Elytra equipment and safely recover already-equipped Elytra items.
- Rename and retexture the Elytra as the Elytra Warp Core using a programmatically generated 16x16 sprite, and a matching mod icon.
- Rebuild the Waystones crafting progression around the Elytra Warp Core, with a vanilla crafting-table recipe by default and an optional Create sequenced-assembly recipe per family when Create is installed.
- Add a native NeoForge configuration screen with separate Common and Client pages, nested sections, translated tooltips, validation, undo/reset controls, and restart prompts.
